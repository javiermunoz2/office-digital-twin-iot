# Datos de simulación

`dataset.csv` (fichero `datatest2`, 9.752 filas) y `dataset_training.csv` (fichero `datatraining`, 8.143 filas) son las columnas de temperatura, humedad y CO2, a resolución de 1 minuto, del dataset público **Occupancy Detection** del UCI Machine Learning Repository. El servicio `publisher` reproduce `dataset.csv` para simular un sensor de oficina antes de tener el hardware real.

> Candanedo, L. M., & Feldheim, V. (2016). *Accurate occupancy detection of an office room from light, temperature, humidity and CO2 measurements using statistical learning models*. Energy and Buildings, 112, 28–39. Dataset: https://archive.ics.uci.edu/dataset/357/occupancy+detection (CC BY 4.0).
